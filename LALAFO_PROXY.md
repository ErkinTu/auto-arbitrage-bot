# Доступ к lalafo.kg с прода: проблема, эксперименты, варианты

**РЕШЕНО 2026-07-19: Decodo residential (KG) работает — см. итог внизу.**

Зафиксировано 2026-07-18 по итогам живой отладки (сессия Erkin + Claude).
Контекст интеграции lalafo — `LALAFO.md`; здесь — только вопрос сетевого
доступа с сервера и согласованные пути решения.

## Проблема

**lalafo.kg за Cloudflare и блокирует датацентровые IP.** С прода
(AWS Lightsail, Frankfurt) и HTML-страницы, и скрытый JSON API отвечают
`403` с челленджем «Just a moment…». С локальной машины (резидентный
кыргызский IP) всё работает без ограничений. mashina.kg с сервера работает
нормально — проблема только у lalafo.

Код деградирует штатно: lalafo-таргеты логируют ошибку и скипаются,
mashina собирается, валидатор карточек на не-410 статусы ничего не
деактивирует. Но lalafo-данных на проде нет, пока нет «чистого» выхода.

## Что уже проверено живьём (не повторять)

| Эксперимент | Результат |
|---|---|
| Запрос с AWS, наш UA `CarAnalyticsMVP/0.1` | 403 challenge (HTML и API) |
| Браузерный User-Agent (Chrome) с AWS | 403 — блок по репутации IP, не по UA |
| **Cloudflare WARP** (proxy-mode, SOCKS :40000) | подключается, внешний IP клаудфлеровский, но lalafo всё равно **403** — их конфиг челленджит и WARP-выходы. WARP с сервера удалён |

Вывод: нужен **резидентный или мобильный IP**; блок репутационный, поэтому
гео, вероятно, не критично (данные КР задаются заголовком `country-id: 12`),
но KG/KZ-выход предпочтителен — окончательно решает только тест.

## Что уже готово в коде (задеплоено на прод)

- Настройка **`LALAFO_PROXY_URL`** (`core/config.py`): прокси применяется
  ТОЛЬКО к lalafo-запросам, mashina и всё остальное — напрямую.
  Форматы: `http://user:pass@host:port` или `socks5://127.0.0.1:1080`
  (для SOCKS в зависимостях `httpx[socks]`). Пусто = напрямую, как локально.
- Включение на проде: одна строка в `.env` + `docker compose up -d`.
  Если прокси умирает — lalafo скипается, бот продолжает работать по mashina.
- Быстрый тест любого кандидата (с сервера):

```bash
curl -s -w "HTTP %{http_code}\n" --proxy "PROXY_URL" \
  -H "device: pc" -H "country-id: 12" -H "language: ru_RU" -H "Accept: application/json" \
  "https://lalafo.kg/api/search/v3/ads/search?category_id=1608&per-page=3&sort_by=newest"
# 200 + JSON = кандидат годен; 403 «Just a moment» = мимо
```

## Варианты выхода (по итогам обсуждения)

Трафик lalafo ≈ **150 МБ/день ≈ 5 ГБ/мес** (лента ~100КБ × 15 марок ×
~96 циклов/день + карточки + ежесуточный валидатор).

### 1. Туннель через домашний/мобильный интернет — 0 сом (рекомендовано)

Обратный SSH-туннель: устройство в КР само держит исходящее соединение к
серверу, роутеру НИЧЕГО не нужно (ни админки, ни проброса портов — обычное
исходящее соединение).

```
AWS ──lalafo──> socks5://127.0.0.1:1080 ──туннель──> устройство в КР ──> lalafo.kg
# на устройстве: ssh -R 1080 ubuntu@63.180.133.249  (+ цикл автопереподключения)
```

- **Телефон (Android + Termux)**: мобильный IP — лучшая репутация у
  Cloudflare (CGNAT, тысячи абонентов за IP) и приватнее домашнего Wi-Fi.
  Требования: телефон всегда на зарядке, ~5 ГБ/мес тарифа, wake-lock и
  отключение оптимизации батареи для Termux. Минус: Android может убивать
  фон, связь рвётся при смене сети (лечится циклом переподключения).
- **Роутер владельца**: если Keenetic/MikroTik/ASUS/OpenWrt — умеет
  WireGuard-клиент сам (схема Б: нужен только веб-интерфейс на 10 мин, мой
  конфиг). Типовой провайдерский TP-Link/Huawei — не умеет, тогда любое
  всегда включённое устройство ЗА роутером (схема А). Перепрошивать чужой
  роутер не предлагаем.
- **Приватность**: сайту виден IP точки выхода — скрыть его нельзя, в этом
  суть схемы. Проект делается для другого человека → правильная точка выхода
  — ЕГО сеть/телефон (с его явного согласия: ~150 МБ/день, его IP видит
  lalafo; риск — блок его домашнего IP на lalafo при злоупотреблении).
  UA не содержит личных данных (плейсхолдер-почта).

### 2. Коммерческий резидентный прокси — $1–10/мес

- **Decodo** (экс-Smartproxy): настоящий бесплатный триал 3 дня / 100 МБ
  (карта для верификации, без списания) — бесплатный тест.
- **DataImpulse**: $5 за 5 ГБ pay-as-you-go, $1/ГБ, трафик не сгорает, без
  KYC — «платный триал» = сразу рабочий месячный объём.
- **IPRoyal**: static ISP от ~$2–3/мес за IP (фиксированный адрес);
  PAYG-резидентка от ~$7/ГБ — дорого.
- При покупке: тип **residential** (не datacenter!), гео KG (редко есть) или
  KZ/RU, **sticky sessions**, протокол http или socks5.
- Oxylabs/Bright Data — только KYC-триалы, enterprise, не наш случай.

### 3. Отброшенные варианты

- **Бесплатные VPN** (Proton Free, Windscribe, публичные прокси-листы):
  выходы — затасканные датацентр-IP в чёрных списках Cloudflare, KG-локаций
  нет, нестабильны. Не тратить время.
- **Cloudflare WARP**: проверен, не проходит (см. выше).
- **KG VPS как прокси** (~$3–5/мес): IP датацентровый — может не пройти;
  тестировать до оплаты. Запасной вариант.
- **Мобильные прокси** ($20–50/мес): работают, но перебор по цене — план Б,
  если резидентные не пройдут.
- Сбор lalafo локально + доливка дампами на сервер: хрупко, руками,
  расходится статистика — только как временный костыль.

## План включения (когда появится endpoint)

1. Тест curl-ом с сервера (команда выше) → ждём `HTTP 200`.
2. В серверный `.env`: `LALAFO_PROXY_URL=...` → `docker compose up -d`.
3. Проверить в логах бота первый успешный цикл:
   `docker compose logs bot | grep "bot fresh sync lalafo"`.
4. lalafo-БД на проде пустая — первый прогрев соберёт по 50 объявлений на
   марку за цикл; catch-up дочитает до 3 доп. страниц; статистика подтянется
   ближайшим rebuild.

## Итог (2026-07-19): Decodo residential работает

Триал Decodo (Residential, Pay per GB) проверен с прода и включён:

- **Kyrgyzstan-выход есть и проходит Cloudflare lalafo** (HTTP 200 и на
  ленту, и на карточки). KZ тоже доступен как запасной.
- **Формат endpoint** (гео и sticky задаются в username, порт 7000):
  `http://user-<USER>-country-kg-session-<ANY>-sessionduration-10:<PASS>@gate.decodo.com:7000`
  Рабочая строка с паролем — только в серверном `.env` (`LALAFO_PROXY_URL`).
- **Ловушка дашборда**: порты 10001+ — sticky-сессии; скопированный оттуда
  endpoint без `-country-...` в username даёт случайную страну (у нас была
  ЮАР). Гео работает только через username-параметры.
- Первый прогрев прошёл: Toyota page=1 → 50 новых, catch-up добрал стр. 2+
  (штатно для пустой lalafo-БД), errors=0.
- **Триал = 100 МБ**, наш расход ~150 МБ/день → хватает на ~полдня. Дальше:
  Decodo PAYG $4/ГБ (~$20/мес) или **DataImpulse $1/ГБ (~$5/мес)** — тип
  residential подтверждён, можно брать дешёвый вариант.
