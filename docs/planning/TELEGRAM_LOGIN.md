# Вход через Telegram — кнопкой на самом сайте (план 18.11.2026)

Статус: **план, не начато.** Затрагивает бота, API и сайт (`../analytics-front`).
Учёт: бэкенд — `SITE_TODO.md`, фронт — `../analytics-front/docs/FRONT_TODO.md`.

## Зачем

Сейчас вход такой: человек сам пишет боту `/login` → бот присылает одноразовую
ссылку (`site_login_tokens`, 10 мин) → по нажатию сайт открывается и меняет
ссылку на сессию в httpOnly-cookie (`/auth/exchange`).

Сессия живёт в том браузере, где **открылась ссылка из Telegram**, а это часто не тот,
где человек хотел войти:

| Где человек | Что происходит сейчас |
|---|---|
| Сайт, установленный на экран «Домой» (PWA, с 18.11), **iPhone** | У такого приложения свои cookie, отдельно от Safari; iOS не открывает ссылки в нём. Ссылка из бота откроется в Safari/браузере Telegram — **войти в приложение нельзя вообще** |
| PWA, **Android** | Cookie общие с Chrome. Ссылка из Telegram во встроенном браузере Telegram — вход туда, не в приложение; в Chrome — сработает. Зависит от настроек Telegram |
| Компьютер, сайт в браузере | Ссылка из Telegram Desktop откроется в браузере по умолчанию — может быть не тот, где человек был |
| Всегда | Нужно знать про `/login`, уйти в бота, вернуться — 3–4 шага |

## Как будет: кнопка «Войти через Telegram»

Вход подтверждается в боте, а сессию получает **тот браузер, где нажали кнопку**
(он сам дожидается подтверждения). Работает одинаково в PWA, во встроенном браузере
Telegram, на телефоне и компьютере.

```
Сайт                         API                              Бот
 │ «Войти через Telegram»     │                                 │
 ├─ POST /auth/tg/start ─────►│ запрос входа: nonce, poll-токен,│
 │◄── ссылка t.me/<бот>?start=login_<nonce>, код «47», 5 мин    │
 │ показывает код 47,         │                                 │
 │ открывает Telegram ────────┼────────────────────────────────►│ /start login_<nonce>
 │                            │                                 │ «Вход на сайт: Chrome, Android,
 │                            │                                 │  18.11 15:02. Код на экране?»
 │                            │                                 │ [12] [47] [83]   [Не я]
 │                            │◄──── подтверждено (код верный) ─┤ «✅ Готово, вернитесь на сайт»
 ├─ POST /auth/tg/poll ──────►│ раз в 2 с, пока ждём            │
 │◄── 200 + Set-Cookie сессии │ (одноразово)                    │
 │ вошёл                      │                                 │
```

### Почему именно так

- **Сравнение кода (12 / 47 / 83)** — защита от подмены: злоумышленник может
  создать запрос входа у себя и прислать жертве ссылку «подтверди». Без кода жертва
  нажала бы «Войти» и отдала свой аккаунт браузеру злоумышленника. С кодом нужно ещё
  увидеть экран, где начат вход. Плюс в боте видно устройство и время, срок — 5 мин.
- **Сессию выдаёт опрос, а не ссылка** — cookie ставится в ответ тому браузеру, который
  начал вход. Ссылок с секретом в чате больше нет (их можно переслать).
- **Без Telegram Login Widget** (официальная кнопка `oauth.telegram.org`): виджет
  привязан к одному домену бота (`/setdomain`, у нас домен ещё сменится — задача 12),
  при первом входе просит номер телефона в браузере, всплывающее окно плохо работает в
  PWA и встроенных браузерах. Можно добавить позже для компьютера, если захотим.
- **Старый `/login` остаётся** запасным путём, пока новый не обкатан.

## Работы

### Бэкенд (0,5–1 дн.)

1. Таблица `site_login_requests`: `id`, `nonce_hash`, `poll_hash` (sha256, как у
   `site_login_tokens` — сами токены не храним), `code` (2 цифры), `status`
   (`pending` / `confirmed` / `denied` / `consumed` / `expired`), `user_id` (после
   подтверждения), `user_agent`/`device` (для текста в боте), `created_at`, `expires_at`
   (+5 мин), `confirmed_at`. Создаёт `create_all` (новая таблица — ALTER не нужен).
2. `POST /api/v1/auth/tg/start` → `{bot_url, code, poll_token, expires_in}`.
   `nonce` — 20 символов `[A-Za-z0-9]` (параметр `start` у Telegram: до 64 символов
   `[A-Za-z0-9_-]`). Лимит: 10 запросов входа в минуту с IP, не больше 3 ждущих с IP.
3. `POST /api/v1/auth/tg/poll {poll_token}` → `pending` / `denied` / `expired` или
   **200 + Set-Cookie** при `confirmed` (общий код с `exchange_login_token`: срок
   сессии, лимит устройств, название устройства) и `consumed` — одноразово, условный
   `UPDATE … WHERE status='confirmed'` против гонки двух опросов. Свой лимит частоты
   (опрос раз в 2 с — это 30/мин на вкладку).
4. Бот: `/start login_<nonce>` → сообщение «Вход на сайт: <устройство>, <время>. Какой
   код на экране?» + 3 кнопки с кодами (один верный, порядок случайный) + «Не я».
   Верный код → `confirmed`; неверный или «Не я» → `denied` (сайт покажет «вход
   отклонён, попробуйте снова»). Повторное нажатие / истёкший запрос — «ссылка
   устарела». Новый человек без `/start` — регистрируется как обычно (middleware),
   входит ролью `user`.
5. `start_source`: `login_<nonce>` записывать как `site_login`, а не как сам nonce
   (`services/start_source.py`), — так видно, сколько людей пришло в бота через вход
   на сайте.
6. Событие `site_login` в `user_events` (способ: `button` / `link`).
7. Тесты: полный путь, неверный код, «Не я», истёк, двойной опрос, чужой poll-токен,
   лимиты; nonce и токены не попадают в логи.

### Сайт (0,5 дн.)

1. Компонент «Войти через Telegram»: на `/login`, в профиле, в `LockedPanel` вместо
   текста «отправьте боту /login».
2. Нажатие → `start` → крупно код («47») + «Откройте Telegram и нажмите 47» + кнопка
   «Открыть Telegram» (ссылка `t.me/…`, `target=_blank`) + таймер 5 мин.
3. Опрос раз в 2 с; при возврате на вкладку (`visibilitychange`) — сразу (на iPhone
   приложение «засыпает», пока человек в Telegram). Остановка по сроку.
4. Успех → `useSession` перечитывает `/auth/me`, возврат туда, откуда пришёл (сохранить
   `route.fullPath` до входа). Отказ/срок — «Попробовать снова».
5. На компьютере — дополнительно QR со ссылкой (открыть бота телефоном), если
   уложимся в бюджет JS; иначе — только ссылка.
6. Подсказку «Установить приложение» не прятать: после этой задачи вход в PWA работает.

### Проверка (0,25 дн.)

Матрица: iPhone Safari · iPhone PWA · Android Chrome · Android PWA · встроенный браузер
Telegram (iOS и Android) · компьютер (Telegram Desktop + браузер). В каждой —
вход, «Не я», неверный код, истёкший запрос. Тест-бот `@lyambarbot`, локальный стенд.

## Потом (не в этой задаче)

- **Telegram Mini App**: кнопка «Открыть сайт» в боте открывает сайт внутри Telegram,
  вход сам (подпись `initData` от Telegram) — для аудитории, которая живёт в боте, это
  самый короткий путь. Отдельная оценка.
- Убрать старый `/login` со ссылкой, когда новый вход обкатан (метрика: доля входов
  `button` / `link`).
