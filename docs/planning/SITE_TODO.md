# Сайт: заметки владельца и что осталось (09.11.2026)

Локальный стенд и роли — `docs/bot/LOCAL_TESTING.md § Сайт локально`.
Архитектура — `PLATFORM_ADR.md`, API — `docs/api/PUBLIC_API.md §5`.

## Заметки владельца после локального теста (09.11.2026)

1. **Логотипы марок в фильтрах** и другие детали для лучшего визуального опыта.
   Сейчас марки — текстовые чипы. Нужны SVG-логотипы (свои или с лицензией;
   у демо — аббревиатуры в круге), единый размер, обе темы.
2. **Показывается максимум 8 фото**, хотя их бывает больше. Причина:
   миниатюры на странице авто обрезаны `images.slice(0, 8)`
   (`apps/web/app/pages/car/[id].vue`); свайпом в галерее доступны все. Бэкенд
   хранит до `MAX_GALLERY=20` (`services/images.py`) — проверить, не теряем ли
   фото сверх 20. Исправить: все миниатюры (прокрутка) или «+N» на последней,
   открывающая полноэкранный просмотр.
3. **«±N % к рынку» плохо видно на светлых фонах** — сделать чётче (контраст
   бейджа поверх фото). И **порог ±5 %** вместо 3: если цена выше/ниже рынка
   больше чем на 5 % — показываем отклонение; внутри диапазона — обычная
   карточка **без бейджа и подсказок**. Настройка — `PUBLIC_DEAL_THRESHOLD_PERCENT`
   (сейчас 3), на фронте — не рисовать бейдж и строку оценки при `verdict=market`.

## Что ещё не сделано

**Фильтрация и фильтры**
- Нет выбора **модели** (только марки), нет кузова, КПП, привода, руля,
  растаможки, топлива в панели (бэкенд умеет топливо; кузов/КПП/привод — нет).
- Цена/год/пробег — простые поля, без ползунков и гистограммы из демо.
- Города захардкожены списком — брать из базы.
- **Сохранение фильтра с сайта в бота** (уведомления по нему) — не сделано;
  нужен формат обмена фильтрами сайт ↔ бот.

**Аналитика рынка** (раздел для подписчиков)
- Есть только сводка и топ марок. Нет графиков из демо: поступление объявлений
  (mashina/lalafo по дням), динамика цен по пробегу, распределение цен,
  ликвидность (дни до продажи). Данные для части есть (`market/vehicle-summary`).

**Оценка цены авто** («Оценить мою машину»)
- Мастера на сайте нет. Бэкенд готов (`/market/vehicle-summary`, `/estimate`) —
  нужен экран: марка → модель → год → пробег → результат с графиком.

**Количество объявлений и графики — проверить верность**
- Счётчик «Показать N» с фильтром «только выгодные» — приблизительный (`≈`).
  Точно и быстро — хранить `market_diff_percent` в `listings`.
- Сверить цифры сводки с админ-панелью и ботом на проде.
- Локально у новых объявлений часто «нет оценки» — статистику пересчитывает
  worker (локально не запущен); на проде — проверить долю без оценки.

**Карточка и страница авто**
- «Похожие предложения» на странице авто.
- Полноэкранный просмотр фото (см. п. 2).
- Живые обновления ленты («пришли N новых» без перезагрузки).

**Пользователи и роли**
- Избранное только на устройстве — синхронизация для вошедших.
- Админ-раздел: есть база пользователей; нет платежей, парсеров, обзора.

**Выкат**
- Контейнер Nuxt в compose, блок `{$SITE_DOMAIN}` в Caddy (подготовлен,
  закомментирован), `SITE_URL` и `NUXT_PUBLIC_BOT_URL` на проде.
- Влить и выкатить `feature/public-feed-api` и `feature/roles` (миграции:
  индекс ленты, таблицы сессий) — между циклами бота.
- SEO: `sitemap.xml`, `robots.txt`, Open Graph по умолчанию; CSP-заголовки сайта.
- Мониторинг: Sentry фронта, внешний пинг `/health/ready`; e2e-тесты (Playwright), CI.
